# 书帖工单 v1

输入是有序 sections（唯一 ASCII id、pages 正整数），页身份为[section_id,1起页号]。合计最多10000页。signature_pages为4..64的4倍数，每帖至多此容量；末帖补到最小4倍数，不强补满容量。逻辑页按章节输入顺序连续进入书帖，空白用null，不能与真实页混淆。

每张纸对应4个folio，每帖有n个folio，外至内的深度d从0起。左装订正面左右页为[n-2d,1+2d]，背面为[2+2d,n-1-2d]；右装订分别交换每面的左右。输出每一面均采用“从该面正视、字头朝上”的工作票坐标。这里不推导特定打印机的走纸翻转、PDF旋转或长短边驱动选项；纸面工单须由操作员按设备规则使用。

geometry全部为整数微米。页位起点左为margin、右为margin+leaf_width+gutter，y均margin；爬移=深度×纸厚，左向右移动、右向左移动。固定页框宽高不变。2×爬移不能大于gutter；页框、双侧margin和原始gutter须容纳于纸张。此为明确的线性向内补偿模型，无裁切、纸张物理形变预测或自动设备校准。输出几何供人工核验。

collation按帖/folio次序恢复非空逻辑页并与输入逐页核对。每页恰出现一次，纸张×4=真实页+空白页。书帖、纸张身份均从1起，不跨任务持久化。输入结构/范围/纸面几何错误退出2且不发布报告；成功先计算全部结果，再原子新建JSON，拒绝任何已有目标（含符号链接）。运行不接触打印机或外网。
